Open source Godot project built around grappling hook movement and mechanics

Controls:
  - w/a/s/d - directional movement
  - left click/e - grapple/detach grapple
  - shift (hold) - use boosters
      - while using boosters: hold space to go up, a/d to steer horizontally, or w/no movement keys to boost forward
  - space - jump
  - ctrl - slam downwards
  - r - reset
